# Public Truth Register

Use this register before publishing product claims.

| Claim category | Required evidence | Public status |
|---|---|---|
| Live website | Successful HTTP/HTTPS check | Live only after check |
| Integration | Authenticated probe + recent successful event | Connected only after probe |
| Automation | Verified workflow + recent successful run | Active only after run |
| Security control | Implemented control + documented scope | Implemented, not certified unless certified |
| Certification | Actual certificate/issuer evidence | Certified only with evidence |
| Revenue | Verified payment path/test evidence | Available only for configured path |
| Customer result | First-party evidence with permission | Publish only when permission exists |

Unknown is a valid state. Do not turn unknown into positive marketing language.
